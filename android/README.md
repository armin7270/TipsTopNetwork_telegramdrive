# اپلیکیشن اختصاصی اندروید TeleDrive 📱

پروژه کامل اپلیکیشن نیتیو اندروید TeleDrive با معماری مدرن، زبان **Kotlin** و طراحی جذاب **Liquid Glass (شیشه‌ای نئونی)**.

---

## قابلیت‌های کلیدی نسخه اندروید
1. **طراحی Liquid Glass:** رابط کاربری مدرن با تم دارک و کارت‌های شیشه‌ای شفاف به همراه انیمیشن‌ها و رنگ‌های نئونی فیروزه‌ای.
2. **اتصال به سرور اختصاصی (VPS Switcher):** امکان تنظیم و تست پینگ آدرس سرور (IP یا دامنه VPS اوبونتو) مستقیماً از داخل برنامه.
3. **احراز هویت امن:** ثبت‌نام و ورود کاربران با توکن‌های JWT ذخیره‌شده در `EncryptedSharedPreferences` با استاندارد AES-256.
4. **سیستم فایل مجازی (VFS):** مرور پوشه‌ها، پیمایش مسیرها (Breadcrumb)، ساخت پوشه جدید، تغییر نام و حذف فایل‌ها.
5. **آپلود چانکی قابل از سرگیری (Resumable Chunking):** تقسیم فایل‌های حجیم به چانک‌های ۱ مگابایتی، محاسبه هش SHA-256 و ارسال به فضای ذخیره‌سازی تلگرام بدون محدودیت.
6. **پخش آنلاین مدیا با ExoPlayer:** استریم مستقیم ویدیو و موزیک با پشتیبانی از Range requests و بدون نیاز به دانلود کامل.
7. **دانلود مستقیم فایل‌ها:** یکپارچه با Android DownloadManager برای بارگیری در پس‌زمینه.

## نحوه اجرا و خروجی APK در Android Studio

### پیش‌نیازها:
- **Android Studio** (نسخه Hedgehog / Iguana / Koala یا جدیدتر)
- **JDK 17** یا بالاتر
- **Android SDK 34**

### مراحل گام‌به‌گام:
1. پوشه `android` را در محیط **Android Studio** باز کنید (`File -> Open -> انتخاب پوشه android`).
2. منتظر بمانید تا فرایند **Gradle Sync** به پایان برسد.
3. برای ساخت نسخه نصبی APK:
   - از منوی بالا گزینه **Build** -> **Build Bundle(s) / APK(s)** -> **Build APK(s)** را انتخاب کنید.
   - فایل خروجی در مسیر زیر تولید می‌شود:
     ```
     android/app/build/outputs/apk/debug/app-debug.apk
     ```
4. برای اجرای مستقیم روی گوشی یا شبیه‌ساز (Emulator)، دکمه سبز رنگ **Run (Shift + F10)** را بزنید.

### تنظیم آدرس سرور در اپ:
- در صفحه اول اپلیکیشن (صفحه ورود)، روی دکمه **⚙️ تنظیم آدرس سرور (VPS)** ضربه بزنید.
- آدرس سرور خود را وارد کنید (مثلاً `http://YOUR_SERVER_IP:8000` یا دامنه شخصی).
- با کلیک روی دکمه **تست اتصال به سرور** از ارتباط مطمئن شده و ذخیره نمایید.
